# Sachin Verma — Advanced Developer Portfolio

A responsive, dark editorial-style developer portfolio built with React + Vite.

## Features
- Responsive layout with mobile navigation
- Hero section with animated terminal-style code card
- About and education section
- Skill categories
- Filterable project cards with CSS illustrations
- Contact CTA and social links
- No icon library or image assets required

## Run locally
Requirements: Node.js 20+

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Customize before publishing
1. Search the project for `your.email@example.com` and replace it with your real email.
2. Verify every project description, live demo, and repository URL. Update links to exact repositories.
3. Add a downloadable PDF resume link if desired.
4. Update skills to reflect tools you can confidently discuss in an interview.
5. Run `npm run build` before deploying.

## Deploy
Push this folder to GitHub, then import the repository into Vercel or Netlify. Build command: `npm run build`; output directory: `dist`.

## Important
Project cards are a portfolio presentation starter. Confirm that the linked demos and repositories are public and working before sharing with recruiters.
